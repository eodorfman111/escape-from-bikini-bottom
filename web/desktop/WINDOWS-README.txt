CONCH STREET - TROUBLE IN BIKINI BOTTOM
Windows x64 portable edition

START PLAYING
1. Right-click the downloaded ZIP and choose Extract All.
2. Open the extracted ConchStreet-win32-x64 folder.
3. Double-click conch-street.exe.
   If nothing opens, double-click "Start Conch Street.cmd" instead. It checks
   for missing game files and collects diagnostic logs while the game runs.

Keep all files and folders together. Do not run the executable inside the ZIP
or copy it out by itself. You do not need Node, npm, a browser or an account.
The game works offline; the field guide's external source websites need internet.

Choose Survival or Just explore, select your character, then start.
Walk through open doors to enter rooms automatically.

CONTROLS
WASD / arrow keys: move
Mouse: look (drag the view if mouse capture is unavailable)
Left click: fire
Shift: sprint
R: reload
E: collect supplies / discover secrets
B: repair a breached front door while nearby
Esc / P: pause

The pause menu includes music volume, look sensitivity and graphics quality.
Try Economy graphics if movement is choppy.
The application menu includes fullscreen and quit.

BUILD NOTES
This is an unsigned preview build. Windows may show an unknown-publisher
warning. Native Windows gameplay has not been verified.
Progress lasts for the current run and is not saved when the app closes.
No installer or automatic updater is included. Delete the extracted folder
to remove the game.

IF THE GAME DOES NOT OPEN
Extract this ZIP into a NEW folder. Do not replace files in a folder containing
an older game that may still be running.
Run "Start Conch Street.cmd" and leave its console window open.
Its messages show the diagnostic log folder (normally
%LOCALAPPDATA%\ConchStreet\logs). Share the console message and the log files
if the game still fails. You can enter that folder path in File Explorer.
